🎓 AI Study Assistant Chatbot
Chatbot hỏi đáp tài liệu môn học sử dụng RAG và Fine-tuning cho tiếng Việt
📌 Giới thiệu

Project xây dựng một chatbot hỗ trợ sinh viên hỏi đáp dựa trên tài liệu môn học bằng tiếng Việt.
Hệ thống cho phép upload tài liệu học tập (PDF/DOCX), sau đó chatbot sẽ truy xuất nội dung liên quan và trả lời câu hỏi của người dùng.

Ngoài ra, project còn nghiên cứu và so sánh hiệu quả giữa:

RAG (Retrieval-Augmented Generation)
Fine-tuning

trong bối cảnh xử lý tài liệu học tập tiếng Việt.

🚀 Features
📂 Quản lý tài liệu
Upload file PDF/DOCX
Lưu trữ tài liệu
Xử lý và chia nhỏ nội dung tài liệu
🤖 Chatbot hỏi đáp
Đặt câu hỏi bằng tiếng Việt
Trả lời dựa trên tài liệu đã upload
Trích dẫn nguồn nội dung liên quan
Lưu lịch sử chat
📊 Research & Evaluation
So sánh RAG và Fine-tuning
Đánh giá:
Accuracy
Response time
Context relevance
